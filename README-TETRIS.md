# 🎮 테트리스 게임

클래식 테트리스를 웹브라우저에서 즐길 수 있는 게임입니다.

## 🚀 시작하기

1. `tetris.html` 파일을 브라우저로 열기
2. "게임 시작" 버튼 클릭
3. 재미있게 플레이하기!

## 🎯 게임 규칙

- **목표**: 완성된 라인을 만들어 점수 획득
- **라인 완성**: 가로 한 줄이 모두 채워지면 자동 삭제
- **게임 오버**: 새 블록이 생성될 수 없을 때

## 🕹️ 조작법

| 키 | 기능 |
|---|---|
| ← → | 블록 좌우 이동 |
| ↓ | 블록 빠른 하강 |
| Space | 블록 회전 |
| P | 일시정지/계속 |

## 📊 점수 체계

| 삭제된 라인 | 점수 |
|----------|------|
| 1라인 | 100점 |
| 2라인 | 300점 |
| 3라인 | 500점 |
| 4라인 | 800점 |

## 📈 레벨 시스템

- **초기 속도**: 1초에 한 칸 하강
- **레벨 상승**: 10라인 완성마다 레벨 +1
- **속도 증가**: 레벨이 올라갈수록 블록 하강 속도 증가

## 🎵 특징

### 게임 화면
- 레트로 스타일의 초록 테두리 보드
- 실시간 점수, 레벨, 라인 정보 표시
- 게임 오버 모달 창

### 게임 기능
- ✅ 7가지 테트로미노
- ✅ 블록 회전
- ✅ 충돌 감지
- ✅ 라인 완성 감지
- ✅ 자동 하강
- ✅ 일시정지 기능
- ✅ 레벨/속도 시스템

## 🎮 게임 팁

1. **초반 전략**: 빈 공간을 최소화하기
2. **I자 블록 활용**: 4라인 완성으로 보너스 점수
3. **높이 관리**: 블록이 너무 높아지지 않게 주의
4. **속도 적응**: 레벨이 올라갈수록 반응 속도 필요
